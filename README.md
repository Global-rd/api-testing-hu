# API Testing Exercises

This repository contains exercise files for the robot_dreams API testing course. It includes multiple testing frameworks and approaches for API testing practice.

## Included Projects

This repository contains the following submodules:

- **playwright-api-testing**: API testing examples using Playwright with JavaScript
- **python-api-project**: API testing examples using Python
- **python-api-app**: Example API application built with Python
- **rest-assured-api-project**: API testing examples using REST Assured with Java

## Getting Started

To clone this repository with all submodules:

```bash
git clone --recurse-submodules git@github.com:Global-rd/api-testing-hu.git
cd api-testing-hu
